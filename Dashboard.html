ADMINISTRATEUR

Mettre à jour le dashboard

1. Préparer l’assistant Windows
Téléchargez l’assistant ci-dessous. Dans l’Explorateur, affichez les extensions puis renommez Mettre-a-jour.ps1.txt en Mettre-a-jour.ps1.
2. Choisir la version et le dossier
Fermez le dashboard sur tous les postes. Faites un clic droit sur l’assistant puis « Exécuter avec PowerShell ». Choisissez le ZIP et le dossier contenant le HTML actuel.
3. Confirmer l’installation
Vérifiez le dossier affiché. L’ancienne version est conservée dans Sauvegardes_versions. Le dossier Data reste intact. Si Windows refuse le lancement, demandez l’aide de votre service informatique.
Une nouvelle version du dashboard est disponible Le fichier partagé a été mis à jour. Recharge la page pour utiliser la nouvelle version.
